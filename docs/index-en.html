Official-source coverage

Four provider families, one review contract.

The Skill acquires official course requirements only after confirming the board, qualification, A-Level stage, market, subject, and exam year. The host LLM owns syllabus meaning and teaching quality; Python retrieves evidence, renders artifacts, records hashes, and blocks invalid delivery.

Governed workflow

HTML is reviewed before PDF exists.

A handbook is not approved because files exist. Every official requirement is mapped to atomic teaching points, every topic receives its own visual decision, and the LLM personally reviews the complete rendered HTML. Repairs invalidate the previous approval and trigger another full review.

01 · PREFLIGHT

Confirm the exact course

Board, route, market, year, glossary language, teaching style, and external image capability.

02 · ANALYSE

Map atomic teaching points

Official requirements stay traceable to one final topic and visible handbook location.

03 · WRITE + VISUALISE

Create topic-specific teaching

Worked examples and visuals must be semantically useful, not reusable text-box templates.

04 · REVIEW + EXPORT

Inspect, repair, then export

Only hash-bound, LLM-approved HTML can pass the controlled PDF gate.

Questions

What the project does and does not promise.

Is this a finished textbook?

No. It is a governed Agent Skill that creates a handbook for the confirmed course and year. Each generated handbook still requires its own complete review.

Can it fetch every curriculum automatically?

No. Automatic acquisition is limited to the supported AQA, Edexcel, CAIE, and College Board AP routes. Other manual imports are experimental.

Does the Python package decide the topics?

No. The host LLM reads official evidence and owns syllabus interpretation, teaching content, visual judgment, and approval. Python handles retrieval, validation, rendering, recording, and blocking.

Why does PDF export happen last?

The HTML is the review surface. Export remains blocked until the current HTML and its review ledger share the approved hashes.
